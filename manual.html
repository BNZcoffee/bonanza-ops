1. 이 시스템을 사용하는 이유

보난자 커피 코리아는 전국 직영점이 빠르게 늘고 있습니다. 매장이 많아질수록 가장 중요한 것은 모든 매장이 동일한 기준으로 운영되는 것입니다.

그동안 운영 공지는 메신저로 전달되어 시간이 지나면 다시 찾기 어렵고, 새로 입사한 직원은 과거 공지를 알기 어려웠습니다. 이 시스템은 운영 기준과 공지를 한곳에 모아 언제든 다시 확인하고 누구나 같은 내용을 보도록 합니다.

핵심: 공지는 사라지지 않고 계속 쌓입니다. 기억나지 않는 운영 기준이 있다면 언제든 검색해 다시 볼 수 있습니다.

2. 시작하기 — 로그인

별도 설치 없이 휴대폰이나 PC 브라우저에서 바로 사용합니다.

1
직원 코드 입력
운영팀이 발급한 코드를 입력합니다. (예: BCK-001)
2
비밀번호 입력
초기 비밀번호는 코드 기준으로 자동 부여됩니다. (예: BCK-007 → bnz0007) 로그인 후 내 정보에서 변경할 수 있습니다.
3
자동 로그인 (선택)
본인 기기에서만 사용한다면 체크해두면 다음부터 바로 접속됩니다.
로그인 화면 예시
비밀번호를 잊으셨나요? 운영팀에 문의하면 확인하여 안내해 드립니다.

3. 슬랙 계정 등록 (최초 1회)

처음 로그인하면 슬랙 계정 등록 안내가 나타납니다. 업무 알림을 정확한 계정으로 받기 위한 것입니다.

1
안내 창에서 확인
"슬랙 계정이 등록되어 있지 않습니다" 안내가 뜨면 확인을 누릅니다.
2
슬랙 계정 입력
실제 업무에 사용하는 슬랙 계정(이메일 또는 사용자명)을 입력합니다.
참고: 한 번 등록하면 다음부터 안 뜹니다. 내 정보 화면에서 언제든 수정할 수 있습니다.

4. 공지 게시판 살펴보기

로그인하면 공지 목록이 나타납니다. 공지는 성격별로 나뉜 게시판(카테고리)으로 구분됩니다.

메뉴설명
전체보기볼 수 있는 모든 공지를 모아서 봅니다
카테고리별운영 공지, 교육 자료 등 성격별 게시판
저장한 공지따로 저장해둔 공지만 모아보기
공지 게시판 화면 예시

최근 일주일 이내 공지에는 NEW 표시가 붙고, 열람 권한(전 직원 / 매니저 이상)도 함께 표시됩니다.

5. 공지 열람과 확인 처리

공지를 끝까지 읽은 뒤 "확인했습니다" 버튼을 눌러주세요.

1
공지 선택
목록에서 읽을 공지를 누릅니다.
2
내용 확인
본문과 첨부 자료, 참조문서를 확인합니다.
3
확인 처리
"확인했습니다"를 누르면 열람 일시가 기록됩니다.
공지 상세 화면 예시
왜 확인 처리를 하나요? 운영팀이 전 직원의 숙지 여부를 파악하기 위함입니다. 확인하지 않은 공지는 다시 알림으로 안내될 수 있습니다.

6. 첨부파일 보기와 저장

공지에 사진·문서가 첨부되면 첨부 영역에 표시됩니다. 이미지는 본문에서 바로 미리보기로 표시되어 매번 열지 않아도 됩니다.

버튼기능
보기(눈 모양)새 창에서 파일을 바로 확인
저장(아래 화살표)파일을 기기에 다운로드

첨부 가능한 파일 형식

PDF, 이미지(JPG·PNG·GIF·WEBP 등), Word(doc·docx), Excel(xls·xlsx), PowerPoint(ppt·pptx), 한글(hwp·hwpx), 텍스트(txt·csv), 압축(zip) 등을 첨부할 수 있습니다. (파일당 최대 25MB)

영상은 직접 첨부할 수 없습니다. 저장 공간 관리를 위해, 영상은 유튜브(미등록 업로드)나 구글 드라이브 링크를 본문에 넣어 공유해주세요.

7. 자주 보는 공지 저장하기

자주 확인하는 운영 기준은 저장해두면 빠르게 다시 찾을 수 있습니다.

1
공지 열기
저장할 공지 상세 화면을 엽니다.
2
저장 버튼
상단 "저장"을 누르면 금색 "저장됨"으로 바뀝니다.
3
모아보기
왼쪽 "저장한 공지"에서 확인합니다.

8. 업무 신청 (매장 → 본사)

매장 운영에 필요한 사항을 본사에 요청합니다. 법인카드 등록, 매장 보수, 물품 구매 등을 신청하고 진행 상황을 확인할 수 있습니다.

이용 권한: 업무 신청은 매장 매니저와 관리자가 작성합니다. 신청 내역은 매장 단위로 관리되어, 담당 매니저가 바뀌어도 같은 매장의 과거 이력을 이어서 볼 수 있습니다.

신청하는 방법

1
업무 신청 → 새 신청
왼쪽 "업무 신청" 메뉴에서 "새 신청"을 누릅니다.
2
신청 유형 선택
법인카드 등록, 매장 보수 등 유형을 고르면 맞는 입력 항목과 안내가 나타납니다.
3
작성 및 첨부
안내에 따라 작성하고 필요하면 사진·견적서를 첨부합니다.
4
신청 접수
"신청 접수"를 누르면 담당 부서로 전달되고 담당자에게 슬랙 알림이 갑니다.
새 신청 작성 화면 예시

진행 상황 확인

상태의미
접수됨등록되어 담당자 배정을 기다리는 상태
진행 중담당자가 처리를 시작함 (완료 예정일 표시될 수 있음)
처리 완료요청 업무가 완료됨 (처리 완료일·담당자 표시)
반려처리가 어려워 반려됨 (사유 확인 후 재신청 가능)
업무 신청 목록 예시 — 새 신청에는 NEW 표시

탭으로 진행 중·완료·반려를 구분하고, 검색으로 과거 신청을 찾을 수 있습니다.

9. 모바일에서 앱처럼 사용하기

이 시스템은 휴대폰 홈 화면에 추가하면 일반 앱처럼 아이콘을 눌러 바로 열 수 있습니다. 매번 주소를 입력할 필요가 없어 편리합니다.

📱 아이폰 (Safari)

  1. Safari로 접속 주소를 엽니다
  2. 아래 공유 버튼(↑)을 누릅니다
  3. "홈 화면에 추가"를 선택합니다
  4. "추가"를 누르면 완료됩니다

🤖 안드로이드 (Chrome)

  1. Chrome으로 접속 주소를 엽니다
  2. 오른쪽 위 점 세 개(⋮)를 누릅니다
  3. "홈 화면에 추가"를 선택합니다
  4. "추가"를 누르면 완료됩니다
즐겨찾기도 좋아요. 홈 화면 추가가 번거롭다면 브라우저 즐겨찾기(북마크)에 저장해두면 됩니다. 어느 방법이든 항상 최신 버전으로 열립니다.
접속 주소: https://bnzcoffee.github.io/bonanza-ops/

10. 자료 보안 안내

이 시스템의 모든 공지와 자료는 보난자 커피 코리아의 내부 자료입니다.
  • 공지 내용과 첨부 자료를 외부에 공유·유출하지 않습니다.
  • 다운로드한 자료에는 본인 식별 정보가 표시되며, 유출 시 경로가 확인될 수 있습니다.
  • 계정 정보(코드·비밀번호)를 타인과 공유하지 않습니다.
  • 공용 기기에서는 사용 후 반드시 로그아웃합니다.
관리자용 목차
1. 시스템 개요와 관리자 역할 2. 권한 체계 이해하기 3. 공지 작성·수정·예약 4. 참조문서 첨부 (열람권한 충돌 주의) 5. 첨부·카테고리·리마인드 6. 인원 현황 관리 7. 초기 비밀번호 · 슬랙 계정 8. 업무 신청 관리 9. 신청 유형·파트·담당자 설정 10. 신청 개별 열람권한 (교육용) 11. 슬랙 알림 · 리마인드 12. 스프레드시트 자동 연동 13. 보안 및 운영 원칙

1. 시스템 개요와 관리자 역할

이 시스템은 전국 직영점의 운영 편차를 줄이고 운영 기준을 한곳에서 관리하기 위한 것입니다. 관리자는 공지를 관리하고, 매장 업무 신청을 처리하며, 직원 숙지 여부를 확인합니다.

  • 운영 공지·기준 작성 및 게시 (사진·문서 첨부, 참조문서 연결)
  • 게시판(카테고리) 구성 관리
  • 공지별 확인 현황 파악 및 리마인드 발송
  • 전 직원 인원 현황 등록·수정·관리 (파트·권한 지정)
  • 매장 업무 신청 접수·처리 및 신청 유형 관리

2. 권한 체계 이해하기

역할주요 권한
운영팀(관리자)모든 공지·인원·설정·신청 관리, 전체 게시판 작성
구매팀·인사팀해당 부서 게시판 작성·관리
매니저공지 열람·확인, 업무 신청 작성, 우리 매장 신청 이력 열람
바리스타·파티쉐공지 열람 및 확인 (전 직원 공지)
총괄 마스터: 이사·대표·운영팀장 등 전체 총괄 직원은 "총괄 마스터"로 지정할 수 있습니다. 마스터는 부서·매장과 무관하게 전 매장·전 파트의 모든 업무 신청을 열람합니다.

3. 공지 작성·수정·예약

1
카테고리·제목·본문
게시판을 고르고 작성합니다. 편집기에서 서식과 본문 이미지 삽입이 가능합니다.
2
열람 권한 설정
"전 직원" 또는 "매니저 이상"을 선택합니다. 민감한 내용은 "매니저 이상"으로 설정합니다.
3
댓글·첨부·등록
댓글 허용 여부를 정하고 파일을 첨부한 뒤 등록합니다.
공지 작성 화면 예시

수정 · 예약 발행 · 임시저장

  • 수정: 상세 화면의 "수정"으로 내용·첨부 변경. 기준이 바뀌면 새 글 대신 기존 공지를 수정해 최신 유지
  • 예약 발행: 날짜·시간을 지정하면 해당 시각에 자동 게시
  • 임시저장: 작성 중인 글을 저장해두고 나중에 이어서 작성

4. 참조문서 첨부 (열람권한 충돌 주의)

공지를 작성할 때 기존 공지를 참조문서로 첨부할 수 있습니다. 관련 규정·이전 공지를 함께 연결해두면 직원이 맥락을 쉽게 파악합니다.

1
참조문서 추가
작성 화면 하단 "참조문서 추가"를 눌러 기존 공지를 검색·선택합니다.
2
상세에 표시
등록하면 공지 하단에 참조문서가 링크로 표시되어, 직원이 눌러 바로 이동합니다.
열람권한 충돌 확인: "전 직원" 공지에 "매니저 이상" 참조문서를 첨부하면, 등록 시 확인 팝업이 뜹니다.
· 확인: 참조문서의 열람권한도 "전 직원"으로 바뀌어 모두가 보게 됩니다.
· 취소: 작성하던 글은 그대로 두고, 참조문서만 첨부되지 않습니다.
민감한 참조문서가 의도치 않게 공개되지 않도록 이 팝업을 꼭 확인하세요.

5. 첨부·카테고리·리마인드

첨부파일

PDF·이미지·문서 등 여러 파일을 올릴 수 있고, 이미지는 본문에 미리보기로 표시됩니다. 영상은 용량 관리를 위해 직접 첨부가 제한되며, 유튜브·드라이브 링크로 안내합니다. (파일당 최대 25MB)

카테고리 관리

주의: "구매팀", "인사팀" 등 부서 전용 게시판은 게시판 이름이 권한과 연결됩니다. 임의로 변경하지 마세요.

리마인드

대상설명
미확인 직원만아직 확인하지 않은 직원에게만 재알림
전 직원모든 직원에게 다시 표시 (재공지)

6. 인원 현황 관리

"인원 현황"에서 전 직원을 등록·수정·관리합니다. 재직/퇴사 탭, 검색·필터·정렬을 제공합니다.

인원 현황 화면 예시
1
직원 추가
이름·직급·매장·연락처·이메일·입사일을 입력합니다.
2
파트·마스터 지정
본사 담당자는 소속 파트(재무·시설·구매·운영 등)를 선택하고, 전체 열람이 필요한 직원은 "총괄 마스터"에 체크합니다.
3
코드·비밀번호 자동 부여
코드와 초기 비밀번호가 자동 생성되어 안내 창에 표시됩니다.

일괄 등록 · 퇴사 처리

  • 일괄 등록: 스프레드시트에서 이름·매장·직급을 복사해 붙여넣으면 코드·비밀번호가 자동 부여됩니다.
  • 퇴사 처리: 퇴사일을 입력하면 다음 날부터 계정이 자동 비활성화되어 로그인이 차단됩니다.
삭제는 신중히: 직원 삭제는 복구할 수 없고 관리자 비밀번호 확인이 필요합니다. 실제 근무했던 직원은 삭제보다 비활성화(퇴사 처리)를 권장하며, 삭제는 잘못 등록한 계정 정리에만 사용하세요.

7. 초기 비밀번호 · 슬랙 계정

초기 비밀번호 규칙

초기 비밀번호는 직원 코드 기준으로 자동 부여됩니다. 규칙은 bnz + 코드 숫자 4자리입니다.

직원 코드초기 비밀번호
BCK-007bnz0007
BCK-023bnz0023
비밀번호 분실 대응: 별도 찾기 기능은 없습니다. 직원이 문의하면 운영팀이 스프레드시트에서 확인해 안내합니다. (비밀번호 열이 포함된 시트는 소수만 열람하도록 제한하세요.)

직원 슬랙 계정

직원이 처음 로그인하면 슬랙 계정 등록을 안내받습니다. 등록된 슬랙 계정도 스프레드시트에 동기화됩니다.

8. 업무 신청 관리

매장 업무 신청을 본사 담당자가 접수·처리합니다.

조직 단위 권한: 매장 매니저는 자기 매장, 본사 담당자는 자기 파트, 총괄 마스터는 전체를 봅니다. 담당자가 바뀌어도 후임자가 같은 파트·매장 이력을 인수인계 없이 확인합니다.

신청 처리 방법

1
담당자 지정 (필수)
상세 화면에서 담당자를 반드시 지정합니다. 담당자 없이는 진행/완료로 바꿀 수 없습니다.
2
처리 예정일 (캘린더)
완료 예정일을 캘린더에서 선택하고 "진행 중"으로 전환합니다. 담당자에게 예정일 D-1·D-0 오전 9시에 슬랙 리마인드가 갑니다.
3
처리 완료
처리가 끝나면 처리 완료일을 선택한 뒤 "처리 완료"를 누릅니다. 담당자와 완료일이 모두 있어야 완료로 전환되어, 언제 누가 처리했는지 기록됩니다.
신청 상세·처리 화면 예시

처리가 어려우면 사유를 입력해 "반려"합니다. 매장은 상태 변화를 실시간으로 확인합니다.

9. 신청 유형·파트·담당자 설정

"신청 유형 관리"에서 파트와 신청 유형을 구성합니다.

파트 관리

재무·시설·구매·운영 등 업무 파트를 추가·삭제합니다. 파트 소속 직원이 그 파트의 신청을 열람합니다.

신청 유형 관리

1
유형 추가·수정
유형 이름, 담당 파트, 기본 담당자, 아이콘을 지정합니다.
2
입력 양식 구성
신청자가 작성할 항목을 이름·종류(한 줄/여러 줄/날짜)·필수 여부로 자유롭게 구성합니다.
3
신청 가이드
매장이 신청할 때 보여줄 안내문을 작성합니다.
활용: 자주 들어오는 요청을 유형으로 등록하면, 매장은 유형만 고르고 그때그때 내용·첨부만 작성하면 됩니다.

10. 신청 개별 열람권한 (교육용)

특정 신청 건을, 원래 못 보는 직원(다른 매장·다른 파트)에게도 개별적으로 열람 허용할 수 있습니다. 교육 목적에 유용합니다.

1
열람자 추가
신청 상세 화면 하단 "열람자 추가"(마스터·관리자만)를 누릅니다.
2
직원 선택
열람을 허용할 직원을 검색해 추가합니다. 해당 직원만 이 신청을 볼 수 있게 됩니다.
예시: 잘 처리된 "매장 보수" 건을 신입 매니저 교육용으로 다른 매장 매니저에게 보여줄 때 사용합니다. 추가/제거는 언제든 가능합니다.

11. 슬랙 알림 · 리마인드

신청 접수 시 담당 파트 슬랙 채널로 자동 알림이 가고, 처리 예정일이 다가오면 담당자에게 리마인드가 갑니다.

1
슬랙 웹훅 발급
슬랙 관리자 페이지(api.slack.com/apps)에서 "Incoming Webhooks"를 켜고 채널별 웹훅 URL을 만듭니다.
2
파트에 입력
신청 유형 관리의 각 파트에 웹훅 URL을 입력·저장합니다.
3
자동 발송
접수 시 그 채널로 신청 정보가 전송되고, 예정일 D-1·D-0 오전 9시에 미완료 건 리마인드가 발송됩니다.
참고: 파트 채널에 웹훅을 걸어두면 담당자가 바뀌어도 채널 멤버만 조정하면 됩니다.

12. 스프레드시트 자동 연동

인원 현황과 업무 신청은 구글 스프레드시트에 자동 연동되어, 앱 변경 사항이 주기적으로 반영됩니다.

  • 인원 현황: 직원 추가·수정·삭제가 약 5분 주기로 시트에 반영 (파트·마스터·슬랙·비밀번호 포함)
  • 업무 신청: 신청 유형·신청자·매장·신청일·내용·처리완료일·담당자가 한 시트에 리스트업되어, 필터로 원하는 내용을 골라볼 수 있습니다.
  • 앱이 원본이며 시트는 조회·공유용입니다. 정보 변경은 항상 앱에서 진행합니다.
보안 주의: 동기화 시트에는 비밀번호 열이 포함됩니다. 시트 공유는 운영팀 등 소수로 엄격히 제한하세요.

13. 보안 및 운영 원칙

  • 직원 개인정보(연락처·이메일·슬랙·비밀번호)는 업무 목적 외로 사용하지 않습니다.
  • 비밀번호가 포함된 동기화 시트는 소수만 열람하도록 제한합니다.
  • 직원 삭제 등 되돌릴 수 없는 작업은 반드시 확인 후 진행합니다.
  • 민감한 공지는 열람 권한을 "매니저 이상"으로 설정합니다.
  • 공지·신청 유형은 명확하게 작성해 매장 간 해석 차이가 생기지 않도록 합니다.
이 시스템의 목적은 전 매장이 동일한 기준으로 운영되도록 하는 것입니다. 정확하고 일관된 관리가 브랜드의 운영 품질을 높입니다.
